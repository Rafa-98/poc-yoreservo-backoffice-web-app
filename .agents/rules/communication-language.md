# Communication language

- All conversation with the user is in **English**: respond in English, even if the user's message contains Spanish.
- Project documentation (README, `docs/`, rules, code comments, commit messages) is written in English.
- This applies only to communication and documentation. The **app's UI copy** is localized in `/locales` (Spanish by default, plus English) as defined in `design-system.md`.
